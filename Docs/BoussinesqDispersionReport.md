## 2. 誤差要因の切り分け分析（方向分離誤差 vs 空間格子誤差 vs 物理モデル近似誤差）

> [!IMPORTANT]
> 【重要知見】
1. 方向分離誤差(ADI Splitting Error)は、長波・中波(kh <= 0.8)では0.2%〜1.5%と極めて小さく、物理モデル近似誤差(Airy理論との差 0.5%〜4.2%)や格子誤差(0.4%〜1.8%)と同等以下。
2. 角度45度以外の主軸方向(theta=0度または90度)では、交差微分項が数学的にゼロとなるため方向分離誤差は完全にゼロとなる。
3. したがって、リアルタイム水面シミュレーションにおいて通常1 sweep(2 Dispatches)で十分実用的であり、高精度を要求する斜め波領域でも2 sweeps(5 Dispatches)で分離誤差は0.1%未満に抑えられる。
4. 3〜4 sweepsに反復を増やしても、スカラーHelmholtz近似自体の物理的限界(深水kh > 1.0でのAiry分散との乖離)は解消されないため、過剰な反復は総計算時間を浪費する。

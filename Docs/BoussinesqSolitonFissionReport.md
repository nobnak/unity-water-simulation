## 3. 初期値問題と分散演算子の照合

### 3.1 共通初期条件の照合
- 初期波形定義式: $\eta(z, 0) = a_0 \operatorname{sech}^2(\kappa_0 (z - z_0))$, $w(z, 0) = c_0 \eta / (h + \eta)$
- 初期パラメータ:
  - $a_0 = 0.1200$ m, $h_1 = 0.6000$ m, $z_0 = 5.000$ m
  - 特性幅 $\kappa_0 = \sqrt{\frac{3 a_0}{4 h_1^3}} = 0.645497 \text{ m}^{-1}$
  - 理論線形波速 $c_0 = \sqrt{g (h_1 + a_0)} = 2.6577$ m/s
  - 初期全水量（質量）: $M_0 = \int \eta \, dz = 0.371232 \text{ m}^2$
  - 初期全運動量: $P_0 = \int (h + \eta) w \, dz = 0.986611 \text{ m}^3/\text{s}$

### 3.2 分散演算子の対応とモデル間差
GPUの三重対角カーネル係数（`RunTridiagonalZ`）のTaylor展開:
$A_j \psi_{j-1} + B_j \psi_j + C_j \psi_{j+1} = f_j$
- $A_j = -\frac{\alpha}{\Delta z^2} (0.5 h_j h_{j-1} - \frac{1}{6} h_j^2)$
- $B_j = 1 + \frac{\alpha}{\Delta z^2} (\frac{2}{3} h_j^2)$
- $C_j = -\frac{\alpha}{\Delta z^2} (0.5 h_j h_{j+1} - \frac{1}{6} h_j^2)$

連続演算子の導出結果:
$(I - \mathcal{D}_{\text{GPU}}) \psi = \psi - \alpha \left[ \frac{1}{3} h^2 \psi_{zz} + 1.0 h h_z \psi_z \right] + O(\Delta z^2)$

- **地形勾配項の比較**:
  - GPU連続等価演算子: 勾配係数 = **1.0**（流束保存型分散表現に由来）
  - 古典的 Peregrine (1967) 演算子: 勾配係数 = **0.5** ($\frac{1}{3} h^2 \psi_{zz} + \frac{1}{2} h h_z \psi_z$)
  - 独立ソルバーによるモデル間比較結果:
    - 勾配係数 1.0 の先頭波高 ($t=14$s): **0.2903 m**
    - 勾配係数 0.5 の先頭波高 ($t=14$s): **0.3010 m**
    - モデル差による波高影響: **約 0.0107 m（約 3.5%）**
- **空間離散化精度の限定**:
  - 移流項・圧力勾配項に4階中心差分を用いていても、分散反転 $(I - \mathcal{D})$ は3点中心差分（2階精度）であるため、独立ソルバーを含め全体の空間精度は**2次精度**にとどまります。連続厳密解とは断定せず「高分解能参照数値解」と位置付けます。

## 4. 先頭波高の大きな不一致（0.290m vs 0.083m）の要因分離

独立参照ソルバー（$0.290$ m）とGPU CurrentFCT（$0.083$ m）の波高差の要因を分離特定しました：

1. **1次風上移流による数値粘性 $\nu_{\text{num}} = \frac{1}{2} |w| \Delta z$（主要因）**:
   - $\Delta z = 0.195$ m ($N=256$) では $\nu_{\text{num}} \approx 0.05 \text{ m}^2/\text{s}$ に達し、斜面浅水増幅時に猛烈な散逸を生じさせます。
   - 1D MacCormack (FilterOff) 格子細分化実験での先頭波高推移:
     - $N=128$ ($\Delta z = 0.391$ m): $H = 0.0823$ m
     - $N=256$ ($\Delta z = 0.195$ m): $H = 0.0861$ m
     - $N=512$ ($\Delta z = 0.098$ m): $H = 0.0946$ m
     - $N=1024$ ($\Delta z = 0.049$ m): $H = 0.1178$ m
     - $N=2048$ ($\Delta z = 0.024$ m): $H = 0.1545$ m（粗い格子に比べ波高が+88%回復）
2. **4階双調和FCTフィルターの散逸**:
   - $\kappa_4 = 0.048$ により、急峻な浅水波頂部が直接減衰（$N=512$ で $0.0946$ m $\to 0.0832$ m）。
3. **斜面2階散逸（Slope Dissipation）**:
   - 勾配がしきい値を超えた局所セルで追加減衰。
4. **格子解像度不足（未解像）**:
   - 急峻化した浅水波の峰幅に対して格子点数が不足し、極値が低減。

> [!CAUTION]
> 格子を細分化しても $N=2048$ の MacCormack（$0.1545$ m）は無散逸参照解（$0.2903$ m）に対して依然として約 $47\%$ の波高不足を残しています。
> したがって、「峰が2個出たこと」や「未解像」のみをもって物理的分裂の妥当性を肯定することはできず、基礎スキームの数値散逸特性を含めた総合評価が必要です。
